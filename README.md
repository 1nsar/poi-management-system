# POI Management System

---

## 📘 Overview
This project implements a **POI (Points of Interest) Management System** using Python.  
The system provides a menu-based interface to manage **POIs**, **POI types**, and **visitors**, and supports multiple analytical queries such as distance calculations, visitor rankings, and data validation.

All data is stored and loaded from a **YAML configuration file**.

---

## ⚙️ Requirements
- **Python:** 3.9+
- **Libraries:** PyYAML, math (standard library)
